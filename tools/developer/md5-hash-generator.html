◆ ABOUT THIS TOOL

What Is MD5?

A fast 128-bit hash that is still everywhere — for checksums, not security.

MD5 (RFC 1321) converts any input into a 128-bit fingerprint, written as 32 hexadecimal characters. It is extremely fast and still widely used to detect accidental corruption: file checksums, cache keys and ETags, deduplication, database sharding, Gravatar URLs and S3 Content-MD5 headers.

Text is hashed as exact UTF-8 bytes, so the result matches md5sum, PHP md5(), Python hashlib.md5 and MySQL MD5().

MD5 is cryptographically broken. Collisions — two different inputs with the same hash — can be generated in seconds on a laptop, so MD5 must not be used for passwords, digital signatures, certificates or any integrity check that an attacker could tamper with.

Browsers don't offer MD5 in Web Crypto, so this tool uses its own compact implementation, verified against the official RFC 1321 test vectors.

⚠ USE IT FOR

Where MD5 Is Still OK (and Where It Isn't)

Know when a checksum is enough and when you need a secure hash.

✓

OK: accidental corruption

Checking a download or copy wasn't damaged in transit, comparing files, deduplicating data and building cache keys.

✓

OK: legacy compatibility

Matching an existing system's IDs, ETags, S3 Content-MD5 headers or Gravatar hashes.

✗

Never: passwords

MD5 can be brute-forced at billions of guesses per second. Use Argon2, bcrypt or scrypt.

✗

Never: signatures & tamper-proofing

Attackers can craft colliding files. Use SHA-256 or SHA-512 for anything security-sensitive.
