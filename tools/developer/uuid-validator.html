◆ ABOUT THIS TOOL

What Makes a UUID Valid?

Format, variant and version — all checked here.

A UUID (also called a GUID) is a 128-bit identifier written as 32 hexadecimal digits in five groups: 8-4-4-4-12, for example 017f22e2-79b0-7cc3-98c4-dc0c0c07398f. Upper and lower case are both allowed.

Two digits carry meaning. The first digit of the third group is the version — how the UUID was made (4 = random, 7 = time-ordered, and so on). The first digit of the fourth group shows the variant: 8, 9, a or b means a standard RFC 9562 UUID.

Valid, non-standard, invalid. Valid means the correct format, the standard variant and a version from 1 to 8 — or the special Nil (all zeros) and Max (all f) UUIDs. Non-standard means the format is right but the variant or version isn't one defined by RFC 9562 (e.g. very old Microsoft GUIDs). Invalid means it isn't a UUID at all — wrong length, wrong characters or misplaced hyphens.

Hidden timestamps. v1 and v6 UUIDs contain a timestamp in 100-nanosecond steps since 15 October 1582; v7 UUIDs start with a Unix timestamp in milliseconds. The validator decodes them, so you can see when a record was created.
