◆ ABOUT THIS TOOL

What Is box-shadow?

The CSS property that adds one or more shadows around (or inside) an element's box.

Each shadow is described by up to six values: horizontal offset, vertical offset, blur radius, spread, colour and the optional inset keyword. Positive offsets move the shadow right and down; blur softens its edge; spread grows or shrinks it before blurring.

Shadows follow the element's border-radius, don't take up layout space and don't affect neighbouring elements — so you can add them freely without breaking a layout.

Real-world shadows are rarely a single hard blur. Designers stack several layers: a tight, darker shadow for contact and one or more large, faint shadows for ambient light. That's what the Layered preset does, and why this generator supports multiple layers.

Use low opacity (5–25%) and a dark, slightly tinted colour rather than pure black. On dark backgrounds, shadows are barely visible — use lighter surfaces or a subtle glow instead.

📐 SYNTAX

box-shadow Values Explained

box-shadow: [inset] x y blur spread colour; — separate multiple shadows with commas.

X

Offset X

Horizontal distance. Positive moves the shadow right, negative left. 0 centres it horizontally.

Y

Offset Y

Vertical distance. Positive moves it down — light from above is the most natural look.

B

Blur radius

How soft the edge is. 0 gives a hard edge; larger values spread the shadow wider and fainter. Can't be negative.

S

Spread

Expands (positive) or shrinks (negative) the shadow before blurring. 0 0 0 3px draws a crisp ring like a focus outline.

C

Colour

Use a translucent colour such as rgba(15, 23, 42, 0.15) so the background shows through.

I

inset

Draws the shadow inside the box, making it look pressed in — handy for inputs and toggles.
