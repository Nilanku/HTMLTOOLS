◆ ABOUT THIS TOOL

What Does a JSON Validator Check?

Whether your text is valid JSON — and, if not, exactly where and why it breaks.

JSON (RFC 8259) is strict: keys need double quotes, strings can't contain raw line breaks, and trailing commas, comments, single quotes, NaN and undefined are all forbidden. One stray character makes the whole document unreadable to JSON.parse, APIs and config loaders.

This validator uses its own strict parser instead of the browser's, so instead of a cryptic “Unexpected token at position 4817” you get the line, column, the offending line with a pointer and a plain-English fix. If a bracket is never closed, it tells you where that bracket was opened.

It also flags problems that are technically valid but dangerous: duplicate keys (most parsers silently keep only the last value) and numbers too large for JavaScript, like 64-bit IDs that would be silently rounded.

Got JSON from a JavaScript object, a Python dict or a hand-edited config? Repair fixes trailing commas, comments, single or curly quotes, unquoted keys, True/False/None, NaN, missing commas and more — and you can undo it.

FAQ

Frequently Asked Questions

JavaScript object literals are more relaxed than JSON. JSON requires double-quoted keys and strings and forbids trailing commas, comments, single quotes, undefined, NaN and functions. Click Repair to convert a JS object literal to valid JSON.

The specification says keys “should” be unique, so duplicates are technically allowed — but behaviour is undefined. JavaScript, Python and most libraries silently keep only the last value, which hides bugs. This validator lists every duplicate with its path and line.

JavaScript stores numbers as 64-bit floats, so integers above 9,007,199,254,740,991 (253−1) are rounded: 12345678901234567890 becomes 12345678901234567000. 64-bit database IDs and Twitter/Snowflake IDs are common victims. Send them as strings to be safe.

It strips comments, removes trailing commas, converts single and curly quotes to double quotes, quotes bare keys, converts True/False/None to true/false/null, turns NaN/Infinity/undefined into null, normalises numbers like .5 or 0x1F and adds missing commas. It tells you exactly what it fixed, and Undo restores your original text.
