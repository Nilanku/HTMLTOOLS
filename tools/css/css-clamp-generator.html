    ◆ ABOUT THIS TOOL

    What Does CSS clamp() Do?

    It keeps a value between a minimum and a maximum while letting it scale fluidly in between.

    clamp(MIN, PREFERRED, MAX) returns the preferred value, but never less than MIN or more than MAX. When the preferred value uses viewport units (vw), the result grows smoothly with the screen width and stops at your limits — fluid typography without a single media query.

    The tricky part is the middle value. To hit exactly your minimum at one screen width and your maximum at another, you need a straight line: a slope (how much the value grows per pixel of screen) and an intercept. This generator does that maths for you and writes it as rem + vw.

    Using rem for the fixed part matters for accessibility. Pure vw values ignore the user's browser font-size setting and barely change when zooming. Mixing rem and vw means text still responds to user preferences.

    Even so, fluid text grows less than normal text when zoomed. WCAG 1.4.4 requires text to reach 200% on zoom; a common rule of thumb is to keep the maximum within about 2.5× the minimum. The tool warns you when you go beyond that.

    📐 THE MATHS

    How the clamp() Value Is Calculated

    Every number in the output, explained.

    m

    Slope

    (max size − min size) ÷ (max width − min width). How many pixels the value grows for each pixel of screen width.

    vw

    vw part = slope × 100

    1vw is 1% of the viewport width, so the slope is multiplied by 100 to express it in vw.

    b

    Intercept

    min size − slope × min width, converted to rem by dividing by the root font size (usually 16px).

    ↕

    Order of the limits

    clamp() always takes the smaller limit first. If your value shrinks as the screen grows, the tool swaps them for you.

    16

    Root font size

    rem values are relative to the html font size. If you changed it (e.g. to 62.5% = 10px), enter that here so the numbers match.

    ✓

    Browser support

    clamp() works in every modern browser since 2020 — no fallback needed.
