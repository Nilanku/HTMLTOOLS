◆ ABOUT THIS TOOL

What Is a UUID?

A 128-bit identifier you can create anywhere without asking a central server.

A UUID (Universally Unique Identifier) — called a GUID in the Microsoft world — is a 128-bit value written as 32 hex digits in five groups: 8-4-4-4-12, for example 3f2b8c1e-9d4a-4f6b-b2e1-7c5a0d9e8f13. The 13th digit tells you the version and the 17th the variant.

Because the space is so large (2122 random possibilities for v4), you can generate IDs independently on many machines, offline, and still not expect a collision in the lifetime of the universe.

Every UUID here is built from crypto.getRandomValues() — the browser's cryptographically secure random generator — never Math.random(). Nothing is sent to a server and nothing is logged.

UUIDs are identifiers, not secrets. They are fine for database keys and filenames, but if you need an unguessable token for password resets or sessions, use a dedicated random token with enough entropy and an expiry.

# VERSIONS

Which UUID Version Should You Use?

Versions defined in RFC 9562 (which replaced RFC 4122 in 2024).

v4

Version 4 — random

122 random bits. The default choice for most apps, APIs and test data. Supported natively by crypto.randomUUID(), PostgreSQL gen_random_uuid() and every language.

v7

Version 7 — time-ordered

A 48-bit Unix millisecond timestamp followed by random bits. IDs sort by creation time, which keeps B-tree indexes compact and inserts fast — the best choice for database primary keys.

v1

Version 1 — timestamp + node

A 60-bit timestamp (100 ns since 1582) plus a node ID. Kept for legacy systems such as Cassandra timeuuid. This tool uses a random node ID instead of your MAC address, for privacy.

00

Nil UUID

All 128 bits set to zero: 00000000-0000-0000-0000-000000000000. Used as a placeholder or "no value".
