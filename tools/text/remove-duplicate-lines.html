◆ ABOUT THIS TOOL

How Duplicate Line Removal Works

Every line is compared with the lines before it; only the first copy is kept, so the list stays in its original order.

Lists collected from spreadsheets, logs, exports or copy-pasted pages often contain the same entry several times. This tool keeps the first occurrence of each line and drops the repeats — without sorting, so the order you had is the order you get.

Real-world lists are messy, so two options decide what counts as “the same”: Case sensitive (turn it off to treat Apple and apple as one) and Ignore spaces at ends, which matches lines that differ only by leading or trailing spaces or tabs. The line that is kept is output exactly as written.

Beyond cleaning, the modes answer common questions about a list: Only duplicates lists each value that appears more than once, Only unique lists values that appear exactly once, and Count shows how often each line occurs, most frequent first.

It uses a hash set, so the work grows linearly with the size of the list — 100,000 lines take a fraction of a second, and big files run in a background thread so the page never freezes.

Values that appear more than once, listed once each: apple, banana. Handy for finding repeated emails, IDs or SKUs.

Values that appear exactly once: cherry. Every copy of a repeated value is left out.

Occurrences per value, most frequent first: 3 apple, 2 banana, 1 cherry.
