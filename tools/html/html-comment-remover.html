◆ ABOUT THIS TOOL

Why Remove HTML Comments?

Comments are invisible on the page — but not in the source.

HTML comments (<!-- … -->) are notes for developers. Browsers don't display them, but they're still downloaded and anyone can read them with View Source. Old code, TODO notes, internal URLs and build information often end up there.

Removing them makes pages a little smaller and keeps internal details private. Unlike a simple search-and-replace, this tool reads HTML the way a browser does, so it only removes real comments.

What's protected. Inside <script> and <style> (and <textarea>, <title>, <xmp>, <iframe>, <noembed>, <noframes>), <!-- is just text — removing it could break JavaScript or CSS. The same goes for attribute values like title="<!-- -->", <![CDATA[ … ]]> blocks and <!DOCTYPE>.

Unclosed comments. A <!-- without a closing --> hides everything after it in a browser. The tool doesn't delete the rest of your document — it leaves that part unchanged and tells you the line number so you can fix it.
