◆ ABOUT THIS TOOL

About HTML Entity Encoding & Decoding

Safely render reserved markup characters, prevent XSS vulnerabilities, and parse raw entities.

In HTML, characters like <, >, &, and quotes are reserved syntax tokens used to define tags and attributes. If you want these characters to display as literal text on a webpage rather than being interpreted as code, they must be converted into their respective HTML character entities.

The Toolyard HTML Entity Encoder / Decoder converts raw text and special characters into named (e.g. &amp;), decimal (e.g. &#38;), or hexadecimal (e.g. &#x26;) entities, or decodes messy entity-encoded strings back into readable text entirely within your browser.

⚙ FORMATS & STANDARDS

Supported Entity Formats & Standards

Understanding named, decimal, and hexadecimal character representations in HTML5.

&

Named Entities (e.g. &amp;, &lt;, &copy;)

Human-readable entity names for common characters like ampersands, angle brackets, quotes, and international currency or copyright symbols.

#

Decimal Entities (e.g. &#60;, &#62;)

Unicode code points expressed in base-10 decimal format, universally supported across all browsers, XML parsers, and email clients.

0x

Hexadecimal Entities (e.g. &#x3C;, &#x3E;)

Unicode code points in base-16 hex format, ideal for security sanitization, escaping inline script payloads, and international typography.
