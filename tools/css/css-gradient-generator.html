◆ ABOUT THIS TOOL

What Is a CSS Gradient?

A smooth transition between two or more colours, drawn by the browser — no image file needed.

A CSS gradient is a generated image, so it's used anywhere an image can go: usually background or background-image, but also border-image, mask-image and list-style-image. Because the browser draws it, a gradient is resolution-independent, weighs only a few bytes and never needs an extra HTTP request.

There are three kinds. Linear gradients run along a straight line at any angle. Radial gradients spread outwards from a centre point as a circle or ellipse. Conic gradients sweep around a centre point like the hands of a clock — ideal for pie charts and colour wheels.

Each gradient is a list of colour stops: a colour plus an optional position. Colours blend between neighbouring stops; two stops at the same position create a hard edge, which is how stripes and segmented bars are made. The repeating- versions tile the pattern after the last stop.

Stops can be partly transparent, so a gradient can fade an image into the page or darken a photo behind text. Use the Grid preview background to see exactly where your gradient is see-through.

📐 SYNTAX

Gradient Syntax Cheat Sheet

The parts of each gradient function and what they do.

L

linear-gradient(90deg, red, blue)

The angle sets the direction: 0deg points up, 90deg right, 180deg down (the default). Keywords like to right or to bottom left work too.

R

radial-gradient(circle at 30% 40%, …)

circle or ellipse (default), an optional size keyword (closest-side, farthest-corner…) and a centre position after at.

C

conic-gradient(from 90deg at 50% 50%, …)

Colours rotate around the centre. from sets the starting angle. Stops can be given in % or degrees.

%

Colour stops: #f00 0%, #00f 100%

Positions are optional — stops without one are spread evenly. Two stops at the same position make a sharp line instead of a blend.

⟳

repeating-linear-gradient(…)

Repeats the stop pattern. End the last stop before 100% (e.g. #000 0 10px, #fff 10px 20px) to see the repeat — great for stripes.

α

Transparency

Use rgba(), hsla() or 8-digit hex (#00000080) for see-through stops. Fading to transparent works in all modern browsers.
