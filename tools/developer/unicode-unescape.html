◆ ABOUT THIS TOOL

How Unicode Unescaping Works

Every escape sequence becomes the character it stands for.

Escape sequences appear wherever text passes through code: JSON from an API (Caf\u00e9), JavaScript source, Python's repr() (\xe9, \U0001f600), byte dumps in logs (\xc3\xa9), HTML (&#233;) and CSS (content: "\2014"). This tool reads the text from left to right and replaces each escape with its character, leaving everything else untouched.

Surrogate pairs such as \uD83D\uDE00 are combined into one character (😀). A half pair on its own isn't a valid character, so it's left as it is and reported.

\x bytes. A run of \xHH escapes is first read as UTF-8 (so \xc3\xa9 is é and \xf0\x9f\x98\x80 is 😀). If the bytes aren't valid UTF-8, each one is read as a Latin-1 character instead, the way Python's \xe9 means é.

U+ lists. If the input contains nothing but U+ code points (U+0048 U+0069), they're joined into text. Inside normal text, U+ notation is left alone.
