◆ ABOUT THIS TOOL

Sorting Text the Way People Expect

A plain computer sort compares character codes — which is why “Zebra” lands before “apple” and “file10” before “file2”. This tool fixes both.

Alphabetical and Natural use your browser's language-aware collation, so accented letters sort with their base letter (é next to e), and upper- and lowercase words are interleaved rather than split into two groups.

Natural additionally compares runs of digits as numbers: chapter 2, chapter 10, chapter 100 — the order a human would choose. It's the default because it is what most lists need.

Code point is the strict computer order (all uppercase before lowercase, by Unicode value) — useful when the result must match what sort, databases or Array.prototype.sort() produce.

Number in line sorts by the first number found in each line (prices, scores, versions, negative and decimal numbers; thousands separators like 1,250 are understood). Lines without a number go to the end. All sorts are stable: equal lines keep their original relative order.

Sort Methods Compared

The same list — item10, Item2, apple, item1, Éclair — sorted each way (A → Z).

A

Alphabetical

Language-aware, digits compared one by one: apple, Éclair, item1, item10, Item2.

2

Natural

Numbers compared by value: apple, Éclair, item1, Item2, item10.

#

Code point

Raw Unicode order, uppercase first: Item2, apple, item1, item10, Éclair (with Ignore case off).

↔

Length · Number · Reverse · Shuffle

Shortest first; by the first number in the line; the current order flipped; or a fair random order (crypto-random Fisher–Yates).
