◆ ABOUT THIS TOOL

Why Character Counts Differ

“How long is this text?” has more than one right answer.

Characters here means what you see on screen (grapheme clusters). The emoji 👩‍💻 is one character, though it is built from three Unicode code points and takes 11 bytes. This matches how phones and most social networks count.

UTF-16 units is JavaScript's string.length and what many databases and APIs measure. Emoji and some rare characters count as 2 here. UTF-8 bytes is the storage size on disk or over the network — essential for database column limits and HTTP headers.

SMS is special: messages using only the GSM-7 alphabet fit 160 characters per message, but a single character outside it — an emoji, a curly quote or most non-Latin letters — switches the whole message to Unicode, which fits only 70. Long messages are split into segments of 153 or 67 characters. The tool tells you which characters forced Unicode.

X (Twitter) uses its own weighting: links count as 23 characters and Chinese, Japanese and Korean characters count double. The X bar here uses that rule for CJK characters and links.
