What Is a Unix Timestamp?

The number of seconds since 1 January 1970, 00:00:00 UTC — the clock computers agree on.

A Unix timestamp (also called epoch time or POSIX time) counts the seconds elapsed since the Unix epoch, 1970-01-01T00:00:00Z, ignoring leap seconds. 0 is the epoch itself, 1767225600 is 1 January 2026 at midnight UTC, and negative values are dates before 1970.

Because it is a single number with no time zone, it is perfect for storing and comparing moments in databases, logs, APIs, JWT exp/iat claims and cookies. You convert it to local time only when showing it to a person.

Different systems use different units: Unix, PHP, Python and most databases use seconds (10 digits today); JavaScript and Java use milliseconds (13 digits); some APIs and Go use micro- or nanoseconds (16 or 19 digits). This converter detects the unit from the number of digits.

Time zones come from your browser's built-in IANA database, so daylight saving time is handled correctly for any date in any zone.
