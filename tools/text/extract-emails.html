◆ ABOUT THIS TOOL

How the Email Extractor Works

It finds real addresses — and skips things that only look like one.

The extractor scans your text for the @ sign and reads the name before it and the domain after it, using the characters that email addresses can actually contain. It works on plain text, HTML source (including mailto: links), CSV and JSON exports, and log files — and with international addresses such as info@münchen.de.

Trailing punctuation is never included: Write to anna@example.com. gives anna@example.com, and an address followed by a sentence like anna@example.com.Thanks is still read correctly.

No false matches. Text like logo@2x.png, icon@3x.webp or user@localhost looks like an address but isn't. With Real domain endings only on, the ending must appear in the official IANA list of 1437 top-level domains (updated October 2026).

Duplicates. The part after @ isn't case-sensitive, so Anna@Example.com and Anna@example.com are the same address and listed once. The part before @ is kept exactly as written.
