◆ ABOUT THIS TOOL

Why Text Ends Up With Extra Spaces

Double spaces, tabs and invisible characters sneak in from PDFs, Word, web pages and emails.

Copying text from a PDF, a Word document, a website or an email often brings unwanted spacing along: double spaces after sentences, tabs used for alignment, non-breaking spaces (&nbsp;) that look normal but don't behave like spaces, and zero-width characters that are completely invisible yet break searches, comparisons and code.

This tool removes all of them. Each cleanup step can be switched on or off, so you control exactly what changes.

Text from PDFs and some emails has a hard line break at the end of every visual line. Join lines, keep paragraphs merges those lines back into flowing paragraphs while keeping the blank lines between paragraphs. Join into one line turns everything into a single line — handy for spreadsheet cells and form fields.

Need to keep code indentation? Turn off Trim line starts & ends — repeated spaces inside lines are still collapsed, but each line keeps its leading spaces.

␣ WHAT IS REMOVED

Spaces This Tool Handles

Characters that look like spaces (or like nothing at all).

␣␣

Repeated spaces

Two or more spaces in a row become one. With Tabs → spaces on, tabs count too.

⇥

Leading & trailing spaces

Spaces and tabs at the start and end of each line — and at the start and end of the whole text.

nb

Unicode spaces

Non-breaking (U+00A0), narrow no-break (U+202F), en/em/thin/hair spaces (U+2000–U+200A), medium mathematical space (U+205F) and the ideographic space (U+3000).

👻

Invisible characters

Zero-width space, non-joiner and joiner (U+200B–U+200D), word joiner (U+2060) and the byte-order mark (U+FEFF). Note: emoji sequences use U+200D — this option can split them.
