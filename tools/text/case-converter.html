◆ ABOUT THIS TOOL

Text Cases and Naming Conventions

From headlines to variable names — every case has its place.

Title Case here is smart: it capitalizes major words but keeps short articles, conjunctions and prepositions (a, an, the, and, of, in, on, to…) lowercase unless they start or end the title or follow a colon — close to AP and Chicago style. Hyphenated words are capitalized on both sides (“Self-Driving”).

Sentence case lowercases everything, then capitalizes the first letter of each sentence and the pronoun “I”. With Keep acronyms on, words like NASA, HTML, iPhone and JavaScript stay exactly as you wrote them.

The code cases split text into words at spaces, punctuation and existing case changes, so XMLHttpRequest, user_id, user-id and User ID all convert cleanly. Each line is converted separately, so you can paste a list.

Remove accents turns “Crème brûlée” into cremeBrulee instead of crèmeBrûlée — safer for identifiers, CSS classes and file names.
