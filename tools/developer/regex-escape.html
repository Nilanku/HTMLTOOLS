◆ ABOUT THIS TOOL

Why Escape Text for a Regex?

Some characters have a special meaning in regular expressions.

In a regular expression, . means “any character”, * means “repeat”, ( ) make a group and so on. If you build a pattern from user input or a fixed string — say, to find $9.99 — those characters must be escaped with a backslash, or the regex will match the wrong things or fail to compile.

Each language escapes slightly differently. This tool follows the actual rules of each one: re.escape in Python 3.7+, preg_quote in PHP 7.3+, Regex.Escape in .NET and regexp.QuoteMeta in Go. For JavaScript and Java it escapes exactly the regex syntax characters, so the JavaScript result works with or without the u and v flags.

Inside [ ]. Inside a character class, only \ ] [ ^ - are special (plus & in Java, and ( ) { } / | with JavaScript's v flag). Choose Inside [ ] to escape just those. With the v flag, also avoid doubled punctuation such as && inside [ ] — it's reserved there.

Code string. In Java, C# and other languages a regex is usually written inside a string literal, so the backslashes must be escaped again. Code string gives you a ready-to-paste literal: /…/ for JavaScript, r'…' for Python, '/…/' for PHP, "…" for Java, @"…" for C# and `…` for Go.
