◆ ABOUT THIS TOOL

How This Regex Tester Works

Your browser's own JavaScript engine — so results match your code.

Type a pattern without the surrounding slashes, pick flags with the buttons, and type or paste your test text. Every match is highlighted as you type. Switch to Matches to see each match with its position, numbered groups and named groups, or to Replace to preview text.replace(regex, replacement).

You can also paste a whole JavaScript literal such as /^\d{3}-\d{4}$/gm into the pattern box — it's split into the pattern and its flags automatically. Copy as /regex/ does the reverse, escaping any / in the pattern for you.

Safe with any pattern. Some patterns, like (a+)+$, take exponentially long on certain text — this is called catastrophic backtracking, and it can freeze a page or a server. Here each test runs in a background worker. If it takes more than about 2 seconds it is stopped and you get a warning, and your browser stays responsive.

JavaScript only. Regex flavours differ: Python, PHP (PCRE), Java and .NET support features JavaScript doesn't, such as possessive quantifiers or inline (?x) comments, and vice versa. Test those patterns in their own language. Your test text is never stored or sent anywhere.

JavaScript (ECMAScript), using the RegExp engine built into your browser — the same one Node.js, Deno and Chrome-based browsers use. Most everyday syntax is shared with Python, PHP, Java and .NET, but some features differ, so test patterns for those languages in their own environment.

Turn on the g (global) flag. Without it, JavaScript stops after the first match — that's how exec(), match() and replace() behave in your code too.

Patterns with nested repetition, such as (a+)+$ or (\w+\s?)+$, can try an exponential number of ways to match when the text almost-but-doesn't match. A few dozen characters can take minutes. This tester stops a run after about 2 seconds and warns you. Fix it by removing the nested quantifier or making the alternatives unambiguous.

Use $1, $2… for numbered groups, $<name> for named groups, $& for the whole match and $$ for a literal dollar sign. With the g flag every match is replaced; without it only the first.
