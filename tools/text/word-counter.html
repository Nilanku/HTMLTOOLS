◆ ABOUT THIS TOOL

How This Word Counter Works

Accurate counts for essays, articles, SEO copy and code comments — in any language.

A word is any run of letters or digits, so contractions (“don't”), hyphenated words (“well-known”) and numbers (“3.14”) count as one word, while punctuation, emoji and symbols are ignored. Chinese and Japanese don't use spaces, so each Han, Hiragana or Katakana character counts as one word — the same convention Microsoft Word uses.

Characters are counted the way people see them: an emoji like 👩‍💻 or a flag 🇮🇳 is one character, even though it's made of several Unicode code points.

Reading time uses an average silent reading speed of 238 words per minute, and speaking time 150 words per minute — useful for blog posts, presentations, video scripts and speeches.

Keyword density shows the words and phrases you use most, as a percentage of all words. Turn on “Ignore common words” to skip filler like “the”, “and” and “of” and see what your text is really about.
