    ◆ ABOUT THIS TOOL

    What Is hreflang?

    An annotation that links the language and regional versions of the same page together.

    If your page exists in several languages — or in one language for several countries, like English for the US and the UK — hreflang tells Google about all the versions so it can show each user the right one. Each version lists itself and every other version with a language code, plus an optional x-default fallback.

    Codes use an ISO 639-1 language (en, hi, as), optionally followed by an ISO 3166-1 region (en-GB, hi-IN) or a script (zh-Hant). Common mistakes — en-UK instead of en-GB, a country code on its own like gb, or es-419, which Google doesn't support — are caught as you type.

    You can deliver the annotations three ways: <link> tags in the <head> of each page, <xhtml:link> entries in an XML sitemap, or an HTTP Link header (handy for PDFs). Pick one method — they all mean the same thing.

    Annotations only count when they're reciprocal: if page A points to page B, page B must point back to A. Google ignores links that aren't confirmed by the other page. That's why the output is the same for every version — copy it to all of them.

    ✓ RULES

    Google's hreflang Rules

    What makes hreflang annotations valid.

    ⇄

    Reciprocal and self-referencing

    Each version lists itself and all the others. If two pages don't point to each other, the annotation is ignored.

    en

    Valid codes

    Language in ISO 639-1, optional region in ISO 3166-1 alpha-2 (GB, not UK), or a script like Hant. Region codes alone and codes like es-419 aren't supported.

    🔗

    Full URLs

    Every URL must be absolute, including https://. Versions may be on different domains.

    ✱

    x-default

    The fallback for languages you don't list — ideal for a language-selector or international home page.
