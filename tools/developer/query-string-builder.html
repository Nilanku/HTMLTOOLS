    How Query Strings Work

    The part after the ? that passes data to a page.

    A query string is the part of a URL after the ?: ?q=red+shoes&size=42. Each parameter is a name=value pair, and pairs are separated by &. Because &, =, #, ? and spaces have special meanings, they must be percent-encoded inside names and values — & becomes %26, for example.

    This builder encodes every name and value for you. Choose %20 for spaces (RFC 3986, safe everywhere) or + for spaces (the format HTML forms and URLSearchParams use). Both are decoded the same way by almost every server.

    Lists. There's no single standard for sending several values under one name. Most servers (Express, Django, Flask, Go, ASP.NET, Java) read repeated names: tag=a&tag=b. PHP and Rails expect tag[]=a&tag[]=b (written as tag%5B%5D, since brackets must be encoded). Some APIs want a comma list: tag=a,b.

    Length. Browsers handle very long URLs, but servers, proxies and CDNs often cut off at 8 KB or less, and some tools still break above about 2,000 characters. The builder warns you when a URL gets that long.
