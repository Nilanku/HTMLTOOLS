What Is a Unicode Escape?

A way to write any character using only plain ASCII.

Every character has a Unicode code point — a number written as U+00E9 (é) or U+1F600 (😀). An escape sequence writes that number in the syntax of a programming language, so source code and data files can contain any character while staying pure ASCII. That avoids broken characters when a file's encoding is wrong.

Each language has its own syntax. JavaScript and JSON use \uXXXX with exactly four hex digits, so characters above U+FFFF — most emoji — become two escapes called a surrogate pair (😀 → \uD83D\uDE00). This tool calculates those for you.

Other formats. ES6 JavaScript accepts \u{1F600}, Python uses \u00e9 and \U0001F600, HTML uses &#xE9; or &#233;, and CSS uses \E9 — the tool adds the required space when a hex digit or space follows.

Non-ASCII only (default) escapes characters above U+007E plus invisible control characters, so normal text stays readable. Tabs and line breaks are kept as they are.
