◆ ABOUT THIS TOOL

What Is SHA-256?

The 256-bit member of the SHA-2 family — the workhorse hash of the modern web.

SHA-256 turns any input — a word, a document, a 4 GB ISO — into a fixed 256-bit fingerprint, written as 64 hexadecimal characters. Change a single bit of the input and the hash changes completely, and there is no practical way to go from a hash back to the input or to find two inputs with the same hash.

It secures TLS certificates, Bitcoin, Git's new object format, software downloads, package lockfiles (sha256-… integrity), JWT HS256/RS256 signatures and AWS request signing.

This tool hashes the exact UTF-8 bytes of your text, so results match sha256sum, Python's hashlib, Node's crypto and every other standard implementation. Watch out for invisible differences: a trailing newline or space produces a different hash.

For passwords, a plain SHA-256 is not enough — it is designed to be fast, which helps attackers. Store passwords with a slow, salted algorithm such as Argon2, bcrypt or scrypt.

Output Formats & Modes

Everything you need for checksums, signatures and integrity hashes.

hex

Hexadecimal (64 chars)

The standard format used by sha256sum, download pages and most APIs. Switch to HEX for uppercase.

Base64 (44 chars)

The compact form used in Subresource Integrity (integrity="sha256-…"), Content-Security-Policy hashes and many webhook signatures.

A keyed hash for verifying webhooks (Stripe, GitHub, Slack, Shopify) and signing API requests. Tick HMAC and enter the shared secret.

Bulk mode: one SHA-256 per input line, in order — handy for hashing lists of emails or IDs (up to 100,000 lines).
