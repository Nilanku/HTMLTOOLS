◆ ABOUT THIS TOOL

What Is an XML Sitemap?

A file that lists the URLs on your site so search engines can find them.

An XML sitemap is a file — usually /sitemap.xml — that lists the pages you want search engines to crawl, optionally with the date each page last changed (lastmod). It's especially useful for new sites, large sites and pages that aren't well linked internally.

This generator follows the sitemaps.org protocol used by Google, Bing and others. Each URL is checked, encoded (spaces and non-English characters become %XX) and XML-escaped (& becomes &amp;), so the file is always valid XML.

Input format. One URL per line. A date may follow after a space, tab or comma: https://example.com/about 2026-09-14. Dates can be YYYY-MM-DD or a full timestamp with a time zone such as 2026-09-14T10:30:00+05:30. Lines starting with # are ignored, and lines starting with / use the Base URL.

Limits. One sitemap may hold at most 50,000 URLs and 50 MB. Longer lists are split automatically into sitemap-1.xml, sitemap-2.xml … plus a sitemap_index.xml that points to them — submit just the index.

Publishing Your Sitemap

After downloading the file:

1

Upload it to the site root

A sitemap at /sitemap.xml can list any URL on that host. One in /blog/ can only list URLs inside /blog/.

2

Add it to robots.txt

Add Sitemap: https://example.com/sitemap.xml so every crawler can find it.

3

Submit it in Search Console

Submit the sitemap (or the index) in Google Search Console and Bing Webmaster Tools to see crawl reports.

4

List only canonical pages

Leave out redirects, error pages, noindex pages and duplicate URLs with tracking parameters.
