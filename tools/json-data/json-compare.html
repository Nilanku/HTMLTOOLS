◆ ABOUT THIS TOOL

What Does JSON Compare Do?

It compares the data, not the text — so formatting and key order never cause false differences.

A plain text diff of two JSON files is noisy: re-indenting, reordering keys or minifying make every line look different. This tool parses both documents and compares them structurally, reporting each real difference with its full path, such as $.users[2].email.

Arrays are aligned intelligently: if an item is inserted at the top of a list, you see one added item — not every following element marked as changed.

Comparing API responses or config files across environments? Ignore keys like updatedAt or requestId that always differ, and ignore array order when lists are unordered sets.

The JSON Patch tab gives you the changes as an RFC 6902 patch — a machine-readable list of add, remove and replace operations that transforms A into B, usable with libraries in every language and with HTTP PATCH APIs.

± CHANGE TYPES

How Differences Are Reported

Every difference is one of three kinds, located by a JSONPath-style path.

+

Added

A key or array item exists only in B. Patch: {"op": "add", "path": "/users/3", "value": …}

−

Removed

A key or array item exists only in A. Patch: {"op": "remove", "path": "/legacy"}

~

Changed

The value differs — including type changes such as "42" → 42. Patch: {"op": "replace", …}

$

Paths

$.a.b[0] in the table; JSON Pointer /a/b/0 in the patch. Keys with special characters are quoted: $["first name"].
