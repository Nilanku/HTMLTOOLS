◆ ABOUT THIS TOOL

Why Sort JSON?

Sorted keys make JSON predictable — easier to read, diff, review and cache.

JSON objects are unordered, so two programs can write the same data with keys in a different order. Sorting the keys gives a canonical form: version-control diffs only show real changes, config files stay tidy, and two API responses can be compared line by line.

This sorter works recursively through every nested object by default, or only on the top level if you prefer. Arrays keep their order unless you choose to sort them — array order usually carries meaning.

Choose how keys are compared: Exact sorts by Unicode code point, identical to jq -S and Python's sort_keys=True (uppercase before lowercase). Natural orders numbers inside names the human way (item2 before item10). Case-insensitive ignores capitalisation.

Unlike most online sorters, it never rounds numbers: a 64-bit ID like 12345678901234567890 comes out exactly as it went in, and keys that look like numbers keep the order you choose.

In Exact mode, keys are sorted by Unicode code point, where A–Z (65–90) come before a–z (97–122). This matches jq -S, Python json.dumps(sort_keys=True) and most canonical JSON tools. Choose Case-insensitive to mix them.
