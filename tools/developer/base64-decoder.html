◆ ABOUT THIS TOOL

How Base64 Decoding Works

Turning 4 text characters back into the 3 original bytes.

Base64 decoding reverses the encoding process: every group of four characters maps back to three bytes of the original data. The result can be plain text (JSON, XML, a config file, a message) or binary data such as an image, PDF or font.

This decoder reads the bytes as UTF-8 by default, so non-English text and emoji come out correctly. If the text looks garbled (é instead of é), switch to Latin-1 for older Windows/ISO-8859-1 data.

When the decoded bytes aren't readable text, the tool recognises the file type from its signature (“magic bytes”) — PNG, JPEG, GIF, WebP, PDF, ZIP, fonts and more — shows an image preview, and lets you download the file.

Input is handled tolerantly: line breaks, spaces, missing = padding, the URL-safe alphabet and data: prefixes are all accepted. Genuinely invalid characters are reported with their exact position.
