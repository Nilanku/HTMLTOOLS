◆ ABOUT THIS TOOL

What Is border-radius?

The CSS property that rounds the corners of an element's outer border edge.

border-radius rounds an element's corners — and the background, border, shadow and outline all follow the curve. It's how buttons, cards, avatars and pills get their shape without any images.

The shorthand takes one to four values, applied clockwise from the top-left: top-left top-right bottom-right bottom-left. Missing values copy their opposite corner, so 12px 0 rounds the top-left and bottom-right only.

Each corner can also be an ellipse with separate horizontal and vertical radii, written after a slash: 30% 70% 70% 30% / 30% 30% 70% 70%. Mixing these values creates the soft, organic “blob” shapes popular in modern design.

Percentages are relative to the element's size (width for horizontal radii, height for vertical), so 50% turns a square into a circle and a rectangle into an ellipse. For a pill shape on any size, use a very large pixel value such as 9999px.

📐 SYNTAX

border-radius Patterns

Common shapes and the CSS that makes them.

1

border-radius: 12px;

One value — every corner gets the same radius. The most common card and button style.

2

border-radius: 12px 0;

Two values — top-left & bottom-right, then top-right & bottom-left.

4

border-radius: 12px 12px 0 0;

Four values, clockwise from top-left. This one is a tab: rounded on top, square at the bottom.

○

border-radius: 50%;

A circle on square elements, an ellipse on rectangles. Ideal for avatars.

⬭

border-radius: 9999px;

A pill: the radius is capped at half the shorter side, so the ends are always perfectly round.

/

… / … elliptical radii

Values after the slash are the vertical radii. Use them for leaf, egg and blob shapes.
