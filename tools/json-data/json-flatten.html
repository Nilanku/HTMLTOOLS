◆ ABOUT THIS TOOL

What Does Flattening JSON Mean?

Turning a tree of nested objects and arrays into one level of path → value pairs.

Nested JSON like {"user": {"address": {"city": "Pune"}}} becomes {"user.address.city": "Pune"}. Every leaf value keeps its full path as the key, and arrays use their index: tags.0 or tags[0].

Flat data is what spreadsheets, CSV exports, environment variables, translation files (i18n), Elasticsearch/MongoDB queries, form libraries and analytics tools expect. It also makes it easy to grep or diff deeply nested configs.

Choose a separator that suits the target: . for i18n and query paths, __ for environment variables (DB__HOST), / for JSON Pointer-like keys. Max depth stops flattening at a given level and keeps deeper parts as JSON.

The flattener preserves key order and exact numbers, and warns you when a key already contains the separator or when two paths collide — both would make the result impossible to unflatten unambiguously.

Output Formats

The same data, three ways.

{ }

JSON

{"user.name": "Ada", "tags.0": "x"} — a flat object, ready for i18n files, APIs or the JSON Unflatten tool.

=

key=value

user.name=Ada — one per line, like .properties or .env files. Line breaks inside values are written as \n.

,

CSV

Two columns, key,value, properly quoted — opens directly in Excel or Google Sheets.

[0]

Array style

items.0.price (lodash/dot-object style) or items[0].price (JavaScript/JSONPath style).
