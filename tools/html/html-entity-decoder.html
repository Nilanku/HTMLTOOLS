◆ ABOUT THIS TOOL

What Does an HTML Entity Decoder Do?

It converts character references back into the characters they stand for.

HTML uses character references to write characters that are reserved or hard to type: &lt; for <, &amp; for &, &nbsp; for a non-breaking space, &#8217; or &#x2019; for a curly apostrophe. They show up in page source, CMS exports, RSS feeds, JSON from APIs and database dumps.

This decoder contains the complete list of 2,231 named entities from the HTML Living Standard, plus decimal and hexadecimal references, and turns them back into normal text.

Browser-exact. It follows the HTML rules in detail: some old entities work without a semicolon (&copy, &amp), numeric codes 128–159 map to Windows-1252 characters (&#150; is an en dash), and invalid codes become �. In Attribute value mode, ?a=1&copy=2 stays as it is, just like in a link's href.

Unknown entities such as &nbps; (a typo) are left untouched and listed, so you can find and fix them.
